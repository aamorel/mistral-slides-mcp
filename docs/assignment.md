The assignment
Build an MCP server that generates Google Slides presentations. Connect it to Vibe as a Connector, so a user can ask "Make me 3 slides about [topic]" and get a real Google Slides deck created in their Google Drive. The MCP server must be deployed (not just running locally) so we can test it.

Recommended approach
You are free to choose the approach, tools, and level of depth you think are appropriate. We recommend building an MCP server that exposes a slide generation tool, then registering it as a Connector on Vibe.
Helpful documentation:
Connectors overview: https://docs.mistral.ai/studio/connectors
Managing Connectors: https://docs.mistral.ai/studio/connectors/management
MCP specification: https://modelcontextprotocol.io
Google Slides API: https://developers.google.com/slides/api
Guidelines
Please imagine you will ship this solution to a client. We want to see how you think about MCP server design, API integration, deployment, and making the tool usable from a conversational interface. The slides don't need to be beautifully designed - we want to see a working end-to-end flow.
Also, please have fun with this project. The goal is for you to showcase your technical skills and creativity.

Setup
Once you have created an account and set up AI Studio, we will provide $20 in credits for you to experiment with the API. We just need you to send us your organisation ID.

Submission
When you are done, please send us your GitHub repository link and the URL of your deployed MCP server so we can register it on Vibe and test it. Your repository should include enough information for us to understand and run your solution.
